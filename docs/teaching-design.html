02 · Lab-01 行业洞察智能体 · MCP 工具 · 50 分钟

让学员亲手给智能体装一只「手」

现版本学员只「用」了 MCP；新增代码题让他们体会 MCP 工具 = 一个函数 + 一段描述

步骤学员做什么验收（硬指标）学到什么
1 用起来 · 10'Copilot Chat 切 Agent 模式，运行 /industry-insight，预览周报网页页头显示「模式：智能体研判」智能体 = 指令 + 工具；抓取交给工具，研判交给模型
2 改成自己的 · 15'在 focus.md 加一个自己关注的行业（搜索词、排除词、关注什么），再跑一次周报里出现新行业，且有来源链接换行业不改代码，一份 Markdown 同时驱动抓取和研判
3 基础题 · 20'让 Copilot 加 MCP 工具 get_high_impact：只返回影响等级为「高」的热点单测通过；重启 MCP 后问「本周有哪些高影响事件」，智能体调用新工具工具的 docstring 就是给模型看的说明书，决定它什么时候被调用
3 进阶题 · 选做再加 search_signals(keyword)：按关键词（客户名、竞品名）搜本周信号，做「客户雷达」问「宁德时代本周有什么动静」能返回带链接的信号工具粒度设计：一个工具一个意图
基础题提示词（草稿）
在 Lab-01-Industry-Insight/mcp_server 里新增一个 MCP 工具 get_high_impact：
读取 Lab-01-Industry-Insight/frontend/report.json，
只返回影响等级为「高」的热点，每条包含行业、事件、对我们的影响、来源链接。
逻辑写在 industry_tools.py，server.py 里注册工具并写清楚 docstring，
在 tests/test_industry_tools.py 里加一个单元测试，最后运行测试。
讲师要点
  • 先让学员读 server.py 里现有 4 个工具的 docstring，再动手
  • 强调「改完要重启 MCP 服务器」：命令面板 MCP: List Servers → Restart
  • 答案分支：answer/lab01-basic、answer/lab01-advanced
  • Lab-01 产出的周报会被 Lab-02、Lab-03 继续用
03 · Lab-02 知识总结智能体 · Skills + Copilot SDK · 55 分钟

从「在 Chat 里用」到「做成别人能调的服务」

现版本「用 SDK 做成网页服务」只是跑现成代码；新增代码题让学员亲手改一次 SDK 调用链

步骤学员做什么验收（硬指标）学到什么
1 用起来 · 10'Chat 里让 Copilot 把一篇文章总结成 6 页 PPT，下载用 PowerPoint 打开每页标题是结论句、文字可编辑Skill 怎么被自动选中；knowledge2ppt 调 pptx
2 改成自己的 · 15'改 SKILL.md 的「团队汇报规范」，再生成一次对比新 PPT 体现改动（如多一页「对我们的影响」）把团队习惯写成技能，所有人出的汇报格式一致
3 基础题 · 15'让 Copilot 在 lib/styles.ts 加一种「公司品牌风」（学员描述自己公司的配色和字体）网页上出现新风格，选它生成的 PPT 用了指定配色风格只是传给 Skill 的一段描述，改一个文件即可
3 进阶题 · 选做网页加「汇报对象」选项（领导 / 销售团队 / 技术评审），一路传到 SDK 提示词和 /api/jobs选「销售团队」时，建议页面向销售动作前端 → 路由 → copilot.ts 的完整链路
4 跑服务 · 10'npm run dev，网页上用「本周行业洞察周报」生成 PPT进度页能下载 PPT为 Lab-03 准备好对外 API
基础题提示词（草稿）
在 Lab-02-Knowledge-Summary/lib/styles.ts 的 PRESENTATION_STYLES 里
新增一种风格 brand「公司品牌风」：主色 <学员填>，辅色 <学员填>，
标题字体 <学员填>，适合对内汇报。
照现有三种风格的写法补齐 label、description、emphasis，
并在 app/globals.css 里给 .style-preview.brand 加一个预览样式。
讲师要点
  • 基础题只动 1 个文件（+ 1 段 CSS），混合学员也能做完
  • 进阶题跨 3 个文件，适合研发学员，用来讲「前后端怎么串」
  • 生成一次 PPT 约 3~5 分钟，提醒学员边等边读代码导读
  • 答案分支：answer/lab02-basic、answer/lab02-advanced
04 · Lab-03 串起来 · Copilot Studio · 50 分钟

一句话：看看本周新能源汽车装配行业有什么变化，整理成汇报

2026-10-16 已在演示租户实测跑通 5 段对话；本节是在「讲师事先建好连接器」前提下的学员步骤

步骤学员做什么验收（硬指标）学到什么
1 暴露服务 · 10'端口 3000 设 Public，跑 smoke-test.sh4 项全部打勾云端智能体只能访问公网地址；为什么要 x-api-key
2 建智能体 · 15'建 Standard 智能体、粘贴指令、关闭联网搜索、挂讲师建好的 4 个工具、建连接（填自己的 host 和密钥）Tools 页 4 个工具都是 On工具描述就是提示词；生成式编排怎么选工具
3 测试 · 10'跑 5 段对话：洞察 / 洞察→PPT / 查进度 / 网页→PPT / 一句话串起来拿到自己行业的洞察和一份 PPT长任务异步化：提交即返回进度页
4 改一处 · 15'改一条指令规则或一个工具描述（如「回答末尾写明由哪个团队跟进」），对比前后回答能说出改了什么、行为怎么变了智能体的行为由描述驱动，业务人员也能调
05 · 取舍与风险

评审前要知道的代价

冲突：讲师建连接器 × 每人连自己的服务

连接器里写死一个 host，而每个学员的 Codespace 地址都不同。计划：

  • 首选：连接器加「Set host URL」策略，host 作为连接参数，学员建连接时填自己的地址 + 密钥（需走「自定义连接器」路径，未验证，由 Tarry 在租户里手动试）
  • 保底：学员自己导入 openapi.yaml（2026-10-16 已实测通过，多约 8 步）

其他代价

  • 要新做 4 道代码题的参考答案分支，并逐题确认 Copilot 照提示词能做出来
  • 全班同时让 Copilot 写代码 + 生成 PPT，Copilot 额度消耗明显上升，课前要确认企业预算
  • Studio 测试和 Copilot Credits 同样计费，演示租户要有足够额度
  • 进阶题预计只有部分人能完成，课后作业化
